# CSV自動集計・レポート生成ツール

売上明細のCSVを読み込み、**月別・カテゴリ別の売上集計**と**Markdownレポート**を自動生成する Python スクリプトです。
Excelで毎月手作業していた集計を、コマンド1つで再現できます。Python 標準ライブラリのみで動作し、追加インストールは不要です（Python 3.8 以降）。

## 使い方

```bash
# サンプルデータで実行（引数省略時も sample_sales.csv を読み込みます）
python3 csv_report.py sample_sales.csv

# 自分のCSVを指定
python3 csv_report.py data/2026_sales.csv

# 出力先フォルダを変更
python3 csv_report.py sample_sales.csv -o result
```

## 入力CSVの形式

文字コードは UTF-8（BOM付きも可）。1行目はヘッダーで、次の5列が必須です（列順は問いません）。

| 列名 | 内容 | 例 |
| --- | --- | --- |
| 日付 | `YYYY-MM-DD`（`YYYY/MM/DD` も可） | 2026-08-01 |
| カテゴリ | 商品分類 | 食品 |
| 商品名 | 商品の名称 | 国産米 5kg |
| 数量 | 1以上の整数 | 3 |
| 単価 | 0以上の数値 | 2480 |

金額は `数量 × 単価` で自動計算します。

### 簡易バリデーション

- 必須列が不足している場合はエラーメッセージを出して終了します。
- 日付・数量・単価が不正な行、空欄のある行、列数が合わない行は、警告（行番号と理由）を表示して**その行だけスキップ**し、残りを集計します。スキップ件数はレポートにも記載されます。

## 出力ファイル（`output/`）

| ファイル | 内容 |
| --- | --- |
| `report.md` | 整形済みレポート。概要サマリー（総売上・総件数・平均単価など）、月別表、カテゴリ別表、月別×カテゴリのクロス集計表 |
| `summary_by_month.csv` | 月,件数,数量合計,売上合計 |
| `summary_by_category.csv` | カテゴリ,件数,数量合計,売上合計,売上比率% |

CSV は BOM付きUTF-8 で出力するため、Excel でそのまま開いても文字化けしません。

## ファイル構成

```
csv_report.py       # 本体スクリプト
sample_sales.csv    # サンプルデータ（2026年8〜10月・4カテゴリ・38行）
README.md           # このファイル
output/             # 実行時に自動生成
```

## 想定する案件イメージ

CrowdWorks 等で次のような依頼を想定しています。

- 売上・経費CSVの月次集計の自動化
- Excelで行っている集計作業（ピボット・SUMIF等）のPythonスクリプト化
- ECサイトや POS から出力した売上CSVの商品別・カテゴリ別・店舗別集計
- 請求書・入出金明細CSVの整形と月次レポート作成
- 複数CSVの結合・重複除去・表記ゆれの統一といったデータクレンジング
- 定期実行（cron / タスクスケジューラ）による日次・週次レポートの自動生成
- 集計結果の Excel / Googleスプレッドシート / PDF への出力、メール配信への拡張
- 不正データの検出とエラーログ出力を含む入力チェックの自動化
